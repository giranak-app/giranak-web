# Giranak Web

Angular web app for Giranak (residents, providers, and admin dashboards).

## Tech Stack

- Angular, TypeScript
- Arabic (RTL) and English (LTR)

## Getting Started

Prerequisites: Node.js LTS, Angular CLI.

1. `npm ci`
2. `npm start`
3. App: http://localhost:4200

## Environment

API base URL is set in the environment files. Never commit secrets.
